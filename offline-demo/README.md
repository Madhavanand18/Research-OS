# ResearchOS — Offline Intelligence Demo

## Quick Start

1. **Extract** the ZIP (or copy the folder) to any location.
2. **Double-click `index.html`** to open it in your browser.
3. That's it. No installation, API keys, internet connection, or backend server required.

---

## What This Demo Shows

This is a fully self-contained, static offline version of **ResearchOS** — an AI-powered research intelligence platform.

**Preloaded sample research topic:**
> *"What will be the impact of artificial intelligence on employment in India by 2035?"*

### Features included:
- **New Research** — Simulated research pipeline with realistic progress messages and stage tracking
- **Live Workspace** — Animated 3-column pipeline view (Planning → Web Discovery → Academic → Synthesis → Report)
- **Dashboard** — Statistics charts, claims, contradictions, research gaps, timeline, and executive summary
- **Sources Explorer** — Browsable and filterable source cards with search
- **Knowledge Graph** — Interactive SVG entity graph with click-to-inspect nodes
- **Executive Report** — Full synthesized report with Markdown download and Print support
- **Ask the Research** — Natural language queries answered from the preloaded dataset
- **Projects List** — Two preloaded benchmark research projects

### Second preloaded project:
> *"Small Modular Nuclear Reactors (SMRs) vs. Grid-Scale Battery Storage: 2025-2040 Techno-Economic Viability"*

## About ResearchOS

ResearchOS is an autonomous research intelligence engine. The live version uses Next.js, FastAPI, OpenAI, Tavily, and Semantic Scholar. This offline demo reproduces the UI and demonstrates all major features using preloaded sample data.
